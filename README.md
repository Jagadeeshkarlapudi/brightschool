# Bright Masters Global School - React Website

## Stack
- React
- Vite
- Bootstrap 5
- Bootstrap Icons
- React Router

## Run

```bash
npm install
npm run dev
```

## Replace images

### Logo
Replace:
`public/logo.jpeg`

### Gallery
Replace:
`public/gallery/gallery-1.svg`
through
`public/gallery/gallery-10.svg`

For JPG/PNG photos, update the `src` paths in:
`src/pages/Gallery.jsx`

### Hero image
The home page is prepared to use:
`public/school-building.jpg`

Add your school building photo there. If it is not present, the CSS fallback gradient is used.
